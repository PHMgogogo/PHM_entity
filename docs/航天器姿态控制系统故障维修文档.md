# 航天器姿态控制系统故障维修文档

> **文档编号**：AERO-MNT-ACS-001  
> **系统名称**：姿态控制系统（Attitude Control System, ACS）  
> **文档版本**：V1.0  
> **编制日期**：2026-08-03  
> **适用对象**：地面运维工程师、测试工程师、系统集成人员

---

# 1. 故障概述

## 故障名称

姿态控制系统无法完成姿态调整

## 故障等级

**Ⅱ级（重要故障）**

## 影响范围

- 姿态稳定性下降
- 星敏感器数据异常
- 推进器控制异常
- 任务执行精度降低

---

# 2. 故障现象

出现以下一种或多种情况：

- [ ] 姿态误差持续增大
- [ ] 角速度无法收敛
- [ ] 星敏感器频繁失锁
- [ ] 飞轮持续高速运行
- [ ] 推进器频繁点火
- [ ] 控制器进入Safe Mode
- [ ] 遥测提示ACS Fault

典型遥测日志：

```text
[ACS]
Status = ERROR
Attitude_Error = 2.54 deg
ReactionWheel3 = Saturation
StarTracker = LOST
ControlMode = SAFE
```

# 5. 维修流程

## Step 1 检查供电

检查：

- 主电源
- ACS供电模块
- DC/DC输出

正常值：

```
28V ±5%
```

若异常：

- 更换供电模块
- 检查保险丝
- 检查连接器

---

## Step 2 检查通信

确认：

- CAN总线
- SpaceWire
- RS422接口

查看错误计数：

```text
CAN Error Counter
TX Error < 5
RX Error < 5
```

若异常：

- 更换通信线缆
- 检查终端电阻
- 重启通信模块

---

## Step 3 检查IMU

读取：

```text
Gyro Bias
Accel Bias
Temperature
```

判断：

- 偏置是否超限
- 温漂是否异常

若异常：

执行：

```
IMU Calibration
```

---

## Step 4 检查星敏感器

检查内容：

- 是否锁星
- 星图匹配率
- 曝光时间
- 温度

正常状态：

```text
Tracking = TRUE
Stars > 8
Confidence > 95%
```

若失败：

- 清洁光学窗口
- 检查遮挡
- 重新标定

---

## Step 5 检查飞轮

读取：

```text
Wheel Speed
Motor Current
Temperature
```

重点检查：

- 是否饱和
- 电流是否异常
- 是否存在振动

若飞轮饱和：

执行：

```
Momentum Dump
```

若仍失败：

- 更换飞轮组件

---

## Step 6 检查推进器

检查：

- 阀门状态
- 压力
- 推力

正常：

```text
Pressure > 18 MPa
Valve = NORMAL
```

若异常：

- 更换阀门
- 检查推进剂压力

---

## Step 7 软件检查

确认：

- 控制律版本
- 参数版本
- FPGA版本

校验：

```text
MD5 Checksum
```

若不一致：

重新烧录：

```
ACS Firmware
```

# 7. 验证测试

完成维修后执行：

| 项目       | 判定标准 |
| ---------- | -------- |
| 姿态稳定   | ≤0.05°   |
| 角速度     | ≤0.01°/s |
| 飞轮转速   | 正常范围 |
| 推进器状态 | 无异常   |
| 星敏感器   | 连续锁星 |
| 控制模式   | NORMAL   |

---

# 8. 注意事项

1. 禁止带电插拔飞轮组件。
2. 星敏感器镜头禁止直接接触。
3. 推进系统维修前必须完成泄压。
4. 软件升级前必须备份参数。
5. 所有维修操作须形成维修记录。
